## Visão geral

O projeto será um website de Surf. Nele terão algumas praias específicas com suas informações no tocante a melhor direção de vento, swell e afins. O usuario terá uma tela para se cadastrar e fazer login. Após logar o usuário logar ele irá selecionar a praia preferida. A intenção do site é fazer com que o usuário possa fazer um acompanhamento de suas sessões de surf. Ele poderá colocar quantas horas surfou, quantas ondas pegou, qual tamanho de prancha usou, nota da sessão e isso será compliado numa dashboard que o usuário terá acesso após o login. irá dizer em média quantas horas surfa, o tamanho  O website terá uma dashboard para mostrar essas informações.
